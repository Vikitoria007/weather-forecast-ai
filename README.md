# 🧠 Weather Forecast AI App

Стильное приложение для получения текущей погоды в реальном времени через API wttr.in с графическим интерфейсом на Tkinter и встроенной многослойной нейросетью (Deep Learning) для прогнозирования температуры на завтра.

---

## 🚀 Как запустить

1. Установка зависимостей:
```bash
pip install requests pandas numpy==1.26.4 keras tensorflow
```
2. Запуск приложения:
```bash
python SuperWeatherAI.py
```
## 🧰 Используемые технологии

| Технология | Назначение |
|------------|------------|
| Python 3   | Язык программирования |
| Tkinter    | Графический интерфейс (GUI) |
| Keras / TF | Создание и обучение многослойной нейросети |
| requests   | HTTP-запросы к API погоды |
| pandas     | Формирование датасетов и обработка данных |
| wttr.in    | Бесплатный погодный API |
